# TwilightTown-bot

— 導師與學生互動安全機制設計（2025/07 初稿）

> 為保障學習者與導師雙方安全，建立責任邊界與信任制度，我們設計以下「互動風險防範機制」作為微光鎮基礎治理制度之一。
---

☁️ I. 線上學習基本性質與合法性說明

微光鎮屬「非營利性、自主性、開放式」學習社群。

所有教學均為自願分享、非強制、不收費。

教師無「補習班或特教機構」登記義務，不構成有償教育或營利事業行為。

若有涉及資源共用（例如實體場地合作或推廣），皆將標示清楚「非官方合作、純屬轉貼」。


✅ 根據現行台灣法規，非營利性質、開放參與的線上學習社群 不構成非法補教或教育業務經營行為。


---

⚠️ II. 學習互動中的高風險情境

為避免學生與導師間可能產生的 不當接觸、誤解、或風險關係，微光鎮將設立以下原則：

🔒 1. 一對一輔導與私訊對談管理制度

所有一對一輔導，須事先申請與記錄，禁止任意私訊約談。

導師與學生不可私下透過非平台渠道（如 IG、LINE、Telegram）聯繫，如有必要，需先申報／備案。

導師不得主動提出私下見面邀約。


📹 2. 錄音與陪同制度（三重保障）

階段、機制、備註

對談前＞簽署線上同意書，雙方確認內容可錄製存證
對談中＞建議同步旁聽陪同（如助手）若無旁聽，需開啟錄音（教師或學生皆可）
對談後＞導師簡要回報，回填表單記錄內容，時間與是否錄音


平台將提供安全儲存空間備份，僅在爭議發生時由管理者調閱。


🚫 3. 禁止與未成年學員私下接觸

若導師知曉對方為未成年者，需主動 告知平台，避免不對等互動。

所有實體見面需公開透明、具第三方在場，不得單獨邀約。

發現不當互動即視為停權行為，立即剝奪教師資格。



---

📬 III. 匿名檢舉與申訴制度

設有匿名舉報箱，但所有檢舉需提供至少一項佐證材料（如截圖、錄音、信件等），避免惡意投訴。

管理團隊收到檢舉後將分三階段處理：


> ① 初步檢視 → ② 雙方說明 → ③ 事證核查後決定是否停權或誤會排解

✅ 若為蓄意造假或捏造檢舉，也會保護導師名譽，並記錄檢舉人行為。

---

🎓 IV. 建議實作：私訊輔導申請機制

學生想一對一補課時，需填表單申請

系統安排輔導時段、提醒錄音或安排陪同者

輔導後回報簡要紀錄，作為平台存證

---

✨ 我們的理念

在微光鎮，我們相信：

> 「自由不代表無界，信任也需要機制。」
讓每個教學者安心分享，每位學習者安心學習，是我們長久走下去的根本。

---

🤖 V. Discord Bot 功能實作

為了將上述安全機制自動化並落實於 Discord 伺服器，TwilightTown-bot 將具備以下核心功能：

1. **一對一輔導申請系統**
   * **指令：** `/apply-tutoring`
   * **功能特性：**
     * 24 小時回應時間限制（超時申請自動失效）
     * 只有指定導師或任何導師可操作，防止誤觸
   * **流程：**
     1. 學生使用指令，填寫包含「主題、偏好導師、可配合時段」的申請表單。
     2. 表單內建「同意錄音/陪同」選項，必須勾選方可提交。
     3. 申請將發送至管理頻道，由導師接單（24 小時內）。
     4. 成功後，系統將自動建立臨時私人頻道，並通知雙方。

2. **匿名檢舉系統**
   * **指令：** `/report`
   * **功能特性：**
     * 支援上傳圖片與檔案作為證據
     * 二階段流程：先填寫檢舉資訊，再選擇是否上傳附件
     * 無附件直接提交或透過 DM 補充附件
   * **流程：**
     1. 使用者執行 `/report`，填寫檢舉表單（檢舉對象、事由、補充說明）。
     2. 提交後選擇是否新增檔案證據：
        * **無附件**：直接送出，管理員立即收到
        * **有附件**：進入「上傳檢舉證據」modal，填寫附件說明後在 DM 上傳檔案
     3. 案件將發送至僅有核心管理員可見的保密頻道，並附加所有證據檔案。

3. **課表管理系統**
   * **指令：** `/schedule` (指令群組)
   * **子指令：**
     * **`/schedule add`** [教師用] - 新增課程至課表（需要日期、時間、標題、描述）
     * **`/schedule today`** - 查詢今日課表
     * **`/schedule view`** - 查詢指定日期的課表（需要日期）
     * **`/schedule cancel`** [教師用] - 取消已排定的課程（只能取消自己的課程）

4. **規則與指令查詢功能**
   * **指令：** `/rules`
   * **流程：**
     1. 使用者可隨時查詢所有可用指令及其使用方式。
     2. 機器人會以清晰的嵌入式訊息（Embed）回覆，內容包括：
        * 課表管理指令詳解
        * 一對一輔導申請流程
        * 匿名檢舉使用步驟
        * 核心互動規則提醒

5. **自動化記錄與提醒**
   * 所有輔導申請、處理狀態皆會被系統記錄。
   * 輔導結束後，機器人將自動提醒導師回填簡要紀錄，完成存證。
   * 檢舉記錄完整保存，便於管理員追蹤與後續處理。
